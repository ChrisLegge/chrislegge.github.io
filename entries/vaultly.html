Vaultly

January 2026 – Present

Visit getvaultly.uk

Overview

Vaultly is a personal document vault SaaS product that I designed, built, and deployed entirely solo — from initial concept through to live beta users on both the App Store (TestFlight) and Google Play. The product lets users securely store, organise, and search their important documents, with automatic data extraction from scanned receipts and files.

Building Vaultly end-to-end as a solo developer required me to work across every layer of the stack: a REST API backend, a responsive web app, native iOS and Android apps, and the infrastructure to host and run it all reliably from home.

Tech Stack

The backend is a Python FastAPI REST API with async SQLAlchemy and PostgreSQL, chosen for performance and type safety. The web frontend is built with Next.js 14 (App Router) and React, sharing a typed API client with the mobile apps. The mobile apps are built with React Native (Expo), targeting both iOS and Android from a single codebase.

The entire stack is containerised with Docker Compose and self-hosted on a Mac Mini, with a Cloudflare Tunnel providing HTTPS without exposing a port directly to the internet. A pgvector extension in PostgreSQL lays the groundwork for future semantic search.

OCR & Document Processing

A key feature of Vaultly is automatic data extraction from uploaded documents. I built an OCR pipeline using Tesseract with a custom rule-based Named Entity Recognition (NER) layer to extract merchant names, prices, and dates from scanned receipts and documents.

To improve future accuracy, I built a labelled training dataset of 30+ diverse documents, with plans to fine-tune a DistilBERT model for better entity extraction. The pipeline feeds structured data directly into the database, reducing manual data entry for users.

Authentication & Security

Security was a priority from the start. I implemented a full authentication system including bcrypt password hashing, httpOnly JWT cookies with refresh token rotation and server-side invalidation, account lockout after repeated failed attempts, and per-IP rate limiting to prevent brute-force attacks.

On the mobile apps, I added biometric unlock (Face ID and fingerprint) for a fast and secure login experience. I also handled full UK GDPR compliance: privacy policy, terms of service, cookie consent, audit logging, data export, account deletion, and CAN-SPAM compliant email unsubscribe flows.

Self-Hosted Infrastructure & DevOps

The entire stack runs on a Mac Mini at home using Docker Compose, with a Cloudflare Tunnel providing secure HTTPS access. I built a fully automated CI/CD pipeline using a cron-based deploy script that pulls the latest changes, rebuilds containers, and runs health checks automatically.

Reliability features include nightly PostgreSQL backups to a separate location and push notification alerts sent to my phone if a deploy fails or a service goes down. This gave me hands-on experience with production infrastructure, monitoring, and incident response at a small scale.

Features & Results

Vaultly launched to beta testers via TestFlight (iOS) and Google Play closed testing, with real users actively using the product. Shipped features include document expiry tracking, subscription spike detection, multi-vault organisation, bulk upload, and semantic search groundwork using pgvector embeddings.

Building a complete SaaS product solo — from database schema to App Store submission — taught me more about software engineering in practice than any single course could. Every decision, from choosing a tech stack to handling a production outage, was mine to make and learn from.
